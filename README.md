# Ticketing 🚧 진행중
주최자가 직접 행사를 열고, 이용자가 티켓을 예매하는 플랫폼

## 프로젝트 소개
- 왜 티켓팅인가?: 대규모 트래픽을 견디는 서비스를 만들어보기 위해 티켓팅 도메인이 생각났습니다.
- 목표: 실제 출시와 운영
- MVP 범위: 지정석/비지정석, 회원/비회원 예매, 주최자 행사 개설 및 그룹간 권한 관리

## 진행상황
- [ ] Account: 회원가입, 로그인, 이메일 인증, 토큰 재발급, 비밀번호 재설정
- [ ] Organizer / Event: 설계중
- [ ] Reservation / Payment: 대기
- [ ] 대기열
